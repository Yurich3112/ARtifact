# Monument Images

Add your monument images to this directory with the following filenames:

- `castle-ruins.jpg` - Ancient Castle Ruins
- `town-square.jpg` - Historic Town Square
- `cathedral.jpg` - Old Cathedral
- `bridge.jpg` - Medieval Bridge
- `palace-gardens.jpg` - Royal Palace Gardens
- `tower.jpg` - Ancient Tower
- `opole-synagogue.jpg` - New Synagogue in Opole

## Image Requirements

- Recommended dimensions: 300x200 pixels minimum
- Format: JPG or PNG
- File size: Keep under 500KB for optimal loading

## Updating Monument Data

To add or modify monuments, edit the `monuments` array in `ghost-of-past.js`:

1. Update the coordinates (lat, lng) to match actual monument locations
2. Update the monument names and descriptions
3. Update the Vectary URLs to link to specific AR experiences
4. Adjust the distance values based on user's location
